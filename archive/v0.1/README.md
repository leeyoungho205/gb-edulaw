# 경북교육 AI 법령·업무지원 시스템 — v0.1

교장·교감 대상 업무지원 **프론트엔드 시제품**입니다. `index.html`을 브라우저로 열면 실행됩니다. 외부 라이브러리, 서버, API 키가 필요하지 않습니다.

## 포함 기능
- 모바일·PC 반응형 화면
- 업무 분야 분류 및 6개 시연 시나리오
- 질문 키워드 매칭 (AI 아님)
- 단계별 업무 흐름 및 체크리스트
- 국가법령정보센터 원문 링크
- 문서 초안 수정·복사·인쇄

## 중요 제한
- 업무 절차는 **시연용 예시**이며 법령 검증을 거치지 않았습니다.
- 최신 법령 API, 경북교육청 지침, LLM, 사용자 인증, 데이터 저장 기능은 없습니다.
- 개인정보 및 민감한 사안을 입력하지 마세요.
- 업무상 판단에 사용하기 전 해당 법령의 시행일과 교육청 공식 지침을 확인해야 합니다.

## 개발 로드맵
1. 시연 자료의 조문·업무절차 검수 및 데이터 모델 정의
2. React/TypeScript UI 이전, FastAPI 백엔드 구축
3. 법제처 국가법령정보 API 연계, 문서 버전/시행일 추적
4. 경북교육청 공개 지침 수집·검수 및 출처 표시
5. 검색 기반 RAG, 조문 인용 및 답변 검증
6. 사용자 권한, 접근 기록, 개인정보 보호, 보안 테스트
7. 학교 관리자 대상 사용성 검증 및 정식 배포

## 배포
정적 파일이므로 GitHub Pages에서 새 저장소를 만들고 `index.html`을 올린 뒤 Settings > Pages에서 배포할 수 있습니다. 추후 API 키는 브라우저 코드에 넣지 말고 서버에서 관리해야 합니다.
